# Pending Tests

The current release needs manual verification in these areas:

## Canvas nodes and editing

- Node names are always shown above the card, with no per-node name toggle. The hover-toolbar "Show labels" switch controls the text labels of hover-toolbar buttons for every node type and keeps its state after a reload.
- Node cards have no default outline; only selection, related-node and drop-target states draw an outline.
- The node list and the hover toolbar can lock or hide nodes. A locked node cannot be dragged, resized, edited, deleted or picked up by range selection but stays selectable so it can be unlocked; a hidden node is not rendered and cannot be clicked or targeted by a connection but can be restored from the node list; one undo reverts each lock, hide or rename.
- The bottom-toolbar Node list button (and the hover-toolbar Layers popover) opens a panel that filters nodes by type, renames several selected rows in one action (a single row keeps its exact name, several get number suffixes) and toggles lock/hide per row.
- Dragging a node snaps it to a 16px canvas grid, but an alignment guide wins when an edge or centre comes within 6 screen pixels of another node; the released position matches the drag preview at every zoom level.
- With two or more nodes selected, the selection toolbar shows six align actions (left, horizontal centre, right, top, vertical centre, bottom); with three or more it also shows horizontal and vertical distribute. Each action moves only the selected nodes, and one undo reverts the whole move.
- Every connection shows a short relationship label at its midpoint (Reference image / Reference video / Reference audio / Prompt / Composite, the derived operation such as Background removed / Cropped / Split / Upscaled / Enhanced / Mask edited / Video frame / Generation result, Group content, or a generic Linked fallback); clicking the label selects the connection and the label keeps a constant on-screen size while zooming.
- While a node is dragged, its connections follow the same displacement preview and stay attached after release, and only the dragged nodes re-render instead of the whole canvas.
- Image nodes render as WebP thumbnails whose longest side is 512px on the canvas, and the original is loaded only for the large preview; an older image lazily generates its thumbnail on first render.
- Right-clicking the blank canvas, a node or a connection shows the browser's native context menu, and holding Ctrl while right-dragging draws a stroke; every connection the stroke crosses is cut and one undo restores them.

## Canvas navigation, layout and library

- The left panel shows only the canvas switcher: a group-name header with New and Load, the current group's canvases with node counts, the current canvas highlighted, drag-to-reorder and per-row delete. There is no search field and no Assets or Prompt Library tab.
- Canvases are listed in their stored order (not sorted by updated time), a newly created canvas appears first, and dragging a row reorders it with an insertion line without accidentally navigating; the order persists across reloads.
- The leftmost bottom-toolbar Export canvas button packages the canvas's nodes, connections, viewport and all image/video/audio assets into one zip download whose `projects.json` manifest records the format version, library name and each asset's file.
- Load in the switcher (and the canvas library import) accepts an exported zip, creates a new canvas without overwriting existing ones, restores nodes, connections and viewport, and writes bundled media back to local storage; an existing library name is reused.
- Visiting `/` redirects to the canvas library at `/canvas`, and `/canvas/:id` is the editor. The library lists each canvas as one row with its node/connection stats, updated time and move/export/rename/delete actions, and rows support drag-to-reorder that shares the same stored order as the canvas switcher. The prompt library is `/prompts`, assets are `/assets`, and generation settings live inside canvas node panels.
- The bottom toolbar is centered in the canvas area and scrolls horizontally on narrow widths. Left to right it contains Export canvas; Select/Pan toggle; Undo; Redo; an input/output menu (Assets, Recording); a prompt menu (Prompt, Music Prompt, Speech Prompt, Video Prompt); a generator menu (Image Generation, Music Generation, Speech Generation, Video Generation); a modifiers menu (Image Modifier); Smart Canvas; a conditional Extensions menu; a Zoom popover; a Node list button; and Delete when nodes are selected. The Video media node is not offered here.
- The Zoom tool's popover offers a 5%-500% slider with a live percentage, Reset view, the minimap toggle (highlighted while open) and a Shortcuts entry; it closes on click-away or Escape and stays open while dragging the slider.
- Coordinate rulers render below the top bar as an L (top and left), track pan and zoom, widen their tick spacing when zoomed out, and are display-only so they never capture clicks or drags; each canvas remembers its own zoom and pan across switching and reloads.

## Canvas node panels

- A prompt node is one editable panel showing its title, a "choose from presets" entry and the prompt text field; it feeds generator nodes through an ordinary connection, and the generator's Generate button is always clickable.
- Reference images attach to the prompt node; each Reference N connection gets a label, and the prompt node shows a draggable chip per reference that inserts the matching mention at the caret in the editor.
- A text node's hover toolbar opens a text-style popover for font, size, line height, bold, italic, left/centre/right alignment and text colour; the style is saved on the node and the colour follows the canvas theme when unset.
- The image-generation node is a single inline panel (model, size, count and the Generate button inside the node) whose design size is 412x576 and which scales proportionally; it stays at the bottom of the node stack. Speech generation uses 412x312, music generation 412x244 and the image-modifier node 460x644, all proportional.
- The image-generation Generate button uses the canvas cocoa primary palette (light `#e0cbb0` / dark `#c9ac8b`) rather than a grey fill.
- An image node with content always shows its info at the top-left as name · dimensions · size, omitting missing parts, with no toggle; its hover toolbar merges up/down into the Layers popover.
- Popovers opened from a node panel (presets, model/size pickers, text style) are interactive, and the canvas does not treat a click inside them as a blank-canvas click or move the node.
- The image-generation node's Generate button and the other inline controls keep their spacing inside the node at any size, and the node content is never clipped because it scales from the fixed design size.
- The video prompt node is a dedicated panel that owns the video mode toggle (First/last frames or References) and the image slots below the prompt field: dragging an image node over a slot highlights it and dropping binds that image node id (First frame / Last frame, or up to four Reference slots that fill in order), the filled slot shows a thumbnail with a clear action, a cleared or missing binding renders the slot empty again, and the dragged image animates back to its original position. The video generation node is a fixed 412x576 inline panel whose model, resolution, ratio and duration live inside the node (no mode tabs, no W/H fields and no settings popover) and connects to the video prompt node; both are created from the prompt/generator menus of the bottom toolbar. The Video media node is no longer in the toolbar and is only created by dragging a file out of an Assets node or by a generation.

## Generation

- Firing many generations routes every request through one shared queue with a concurrency limit of 2, so queued images stay visible as waiting instead of all hitting the provider at once.
- A failed generation retries up to 3 times with a 2-second backoff before it is reported as failed.
- Generated images, video, audio and text results are placed on the canvas without a connection back to the generating node; only connections the user creates are kept.
- When a generating image turns into a success it plays one subtle scale + rise + fade entrance (about 0.42s); images already on the canvas do not play it again, and the system reduced-motion setting disables it.
- After a generation completes, the image node's info strip shows the real cost read from the OpenRouter response (`usage.cost`) and marks it as real; when the response has no cost it shows a locally estimated value marked as estimated.
- A video-generation node (or a config node in video mode) set to `minimax/hailuo-3-max` uses OpenRouter's native async video API: the submitted body only carries model, prompt, duration, resolution and aspect_ratio plus `frame_images` in first/last-frame mode or `input_references` in reference mode (the mode and the slot images come from the connected video prompt node, in first/last or reference order and never both at once), the generation node shows model, exactly 480p/768p, 5-15 seconds and the six ratios (1:1 / 3:4 / 4:3 / 16:9 / 9:16 / 21:9) inline without W/H fields or a settings popover, and no `size` / `generate_audio` / `watermark` / `seed` field is sent; other video models (channel models and plugin scripts) keep the previous panel and request path.

## Smart Canvas

- A Smart Canvas board is a fixed-ratio composite canvas with a selectable 1K/2K/4K resolution (default 16:9 / 2K) and a background colour (Transparent / White / Black / Custom) plus background opacity; changing the ratio resizes the board. Images dropped on it become placed layers that stay ordinary editable nodes, show an "on board" badge and dashed outline, and render above the board.
- The board's Auto arrange opens a dropdown with Grid, Single row, Single column and Feature image; every template keeps each image's aspect ratio, fits it inside its cell without distortion, centers it and is undoable.
- The board panel's Layers popover lists placed images front-first with a thumbnail, title, an eye toggle and move-forward / move-backward; hidden layers disappear from the board and the composite, and reordering changes both the on-screen stacking and the composite draw order. Each layer supports one of 16 Photoshop-equivalent blend modes and an individual opacity, with the preview using CSS `mix-blend-mode` and the export using the matching canvas `globalCompositeOperation`.
- Dragging a board onto another board makes it a board layer; the parent renders nested boards recursively in layer order, clipped to their own rectangles, and a board can never be dropped into itself or a descendant. Dragging a board moves its whole placed subtree, and a stored cycle is skipped during render and compose instead of looping.
- The board does not render its composite live: double-clicking it opens the large preview, and the hover-toolbar Save as image node composites it (recursing into nested boards) and adds an image node to the right.
- The board panel's Add text places an editable annotation at the board centre that can be dragged, double-click edited (Escape or blur commits, clearing the text deletes it) and removed with a hover ×; annotations render above placed images and appear in the composite at the same position, size and colour.

## Image tools

- An image node's hover toolbar shows the enabled quick tools, which by default are info, delete, save to assets, download, mask edit, crop, remove background, split, resolution, analyze, extract text, segment and duplicate; the "Show labels" toggle adds the button text labels for every node type and persists.
- Remove background runs the ~42MB background-removal model in a Web Worker and adds a transparent-PNG node to the right, connected and selected; the model is downloaded from Settings → Local models or on first use with progress, and the interface stays responsive.
- Split opens a point-prompt dialog (left-click foreground, Alt or right-click background, with undo-last and clear) that runs MobileSAM locally (ONNX, roughly 45MB downloaded on first use and cached), reports the chosen mask's IoU with an overlay and creates a transparent-background node to the right; the encoder runs once per image so later points stay responsive.
- Resolution has three tabs: Algorithm upscale (1K/2K/4K presets, algorithm choice, output preview, confirm disabled when the source long edge already reaches the target), Algorithm downscale (1024/768/512 presets plus a 64-4096px target, enabled only when the target is smaller than the source) and AI enhance (2x/4x factor and an editable prompt, calling the configured image model with the node image as the only reference). Local results connect as upscale results and AI results as enhance results, and the new node is selected.
- Analyze opens a dialog with the image's dominant-colour palette, its EXIF key/value list (or an empty note) and its perceptual hash; choosing a ratio (1:1 / 4:3 / 3:4 / 16:9 / 9:16) and confirming adds a content-aware cropped image node to the right.
- Extract text sends the image to the configured text model and creates a selected text node to the right; with no text model or key it opens Settings instead, an empty result shows an error and creates no node, and a failed request surfaces the error without a stuck loading toast.
- Double-clicking an image opens the large preview, which has a download button at its bottom; the hover toolbar also offers download and add-to-assets.
- Mask edit requires a painted area and an edit request; confirming writes a "mask annotation" image node below the source (the original with a translucent blue painted overlay) and a result node to the right connected to both, and sends them as two ordinary reference images without the `mask` API parameter. The brush ring tracks the pointer and painting stays smooth while zooming.

## Assets node and local folders

- The toolbar and create menu offer a single Assets node with one folder binding: its files are shown as a plain name-only vertical list (no thumbnails or grid, capped at 200 files with a status note), dragging a file row onto the canvas creates the matching node, clicking a row inserts one at the centre, and the binding and file list are restored on reload and canvas switching.
- Each Assets node binds and remembers its own folder independently (stored per node in IndexedDB, never in the node metadata or the saved project); a newly created Assets node starts unbound with an empty list, so it never inherits another node's folder.
- Dragging an image node onto the Assets node bounces it back to its original position, writes the image into that node's bound folder, shows saving → success/failure and refreshes the file list; the node highlights as a drop target while dragging. The separate output folder and automatic upstream writes are gone.
- The Assets node has a source switcher at the top (Local folder / Extension cache); the choice is stored on the node metadata, survives a reload and canvas switching, and each source keeps its own header actions and list.
- With the OpenCanvas browser extension installed and connected, Extension cache mode lists the cached image file names (same 200-item cap and count as the folder list), and each row can be dragged onto the canvas or clicked to insert a normal image node; with no extension the node shows an "Extension not detected" hint with install guidance and no errors, and local-folder behaviour is unchanged.

## Settings

- Tabs: the Settings dialog shows exactly these tabs in order: Channels, Appearance, Generation, Local models, Prompt sources, Local storage, Cost, Agent, About.
- Channels is a single OpenRouter API-key input whose base URL is fixed to `https://openrouter.ai/api/v1`; the image model is fixed to `openai/gpt-image-2.5-sunburst`, and generation is blocked until a key is set.
- Appearance holds the interface language, the White/Black theme (default White) and the canvas background for newly created canvases (Dots / Lines / Blank, default Dots); an open canvas follows these changes immediately.
- Local models lists each local model (background removal, segmentation) with its size and status and Download / Download again / Delete; Delete confirms, then clears the download state and the browser-cached model files back to Not downloaded.
- Local storage reads only the `infinite-canvas` database and shows IndexedDB usage, total site usage, quota and usage percentage, plus per-store record counts and content size, and refreshes without blocking the page; a row for local-model usage jumps to Local models.
- Cost shows the total USD spend (priced records only), the record count and unpriced count, a per-model breakdown with generation count and summed cost (or an Unpriced label) and the most recent records with time, model, quantity and cost; unpriced records never show as $0.00 and Clear empties the list.
- About shows a flat keyboard-shortcut list whose key caps are readable in both themes, and a version block whose version button opens the release-notes dialog.
- The Settings dialog is a solid panel with a vertical tab strip and a fixed-height, internally scrolling content area; switching tabs never moves or resizes the frame, and there is no intro copy, no import/export and no bottom Done button.
- Next to the Settings button, the account-usage entry opens a panel with the current API key's total, today/week/month usage and remaining quota (or an explicit "no limit set"); it refreshes on open and after each generation and can be refreshed manually. The product name shown in the UI and page title is OpenCanvas.

## Canvas MCP and agent permissions

- The canvas browser bridge and HTTP MCP endpoint run inside the web app on the same port as the canvas. After `cd web; npm run dev`, `http://127.0.0.1:3000/health` and `/config` respond, `GET /` and `/canvas/<id>` still serve the app, and an MCP client at `http://127.0.0.1:3000/mcp` sees 33 canvas tools. The canvas connects automatically on the same origin with no token or config file.
- `canvas_create_node`, `canvas_apply_ops`' `add_node` and `delete_node` accept every built-in type (text, prompt, music prompt, speech prompt, video prompt, image, video, audio, config, image generation, speech generation, music generation, video generation, smart canvas, assets, recording, image modifier); an unknown type is rejected, and `canvas_group_nodes` / `canvas_ungroup_nodes` do not exist.
- Node tools: an MCP client can set lock/hide (`canvas_set_node_flags`), bulk rename (`canvas_bulk_rename`, an exact title for one node or numbered `Title 1`, `Title 2`, … for several), align/distribute (`canvas_align_nodes`; distribute needs 3+ nodes) and duplicate (`canvas_duplicate_node`, default 40/40 offset, selecting the copy). Unknown ids are ignored instead of breaking the canvas.
- Settings → Agent lists one toggle per operation type (10 types, all allowed by default); turning one off blocks that operation, shows a warning and counts it as blocked.
- Every agent operation batch appears in the Agent audit log with its time, operation count, blocked count and a short summary; the log keeps the newest 100 entries, Clear empties it and Restore defaults re-enables every permission. Replaying an entry re-applies the same operations and adds a new entry marked as replayed.

## Appearance and responsive layout

- App chrome (navigation, canvas top bar, bottom toolbar, hover/selection bars, side panel, mini map) uses frosted translucent surfaces with hairline borders, while canvas nodes, popovers, toolbars and asset cards use no drop shadows; state is shown only with borders and outline rings.
- The app and canvas share one warm colour token set, so the library, Settings, dropdowns and inputs use the same warm palette as the canvas in both themes, and the theme switch updates everything.
- All UI text renders with the rounded stack (Baloo 2 for Latin, Resource Han Rounded SC for Simplified Chinese) with real 400/700 weights, falling back to system rounded fonts when the CDNs are unreachable.
- Node-setup, board, layers and text-style popovers share one entrance animation that is disabled when the system reduced-motion setting is on.
- At 375 / 768 / 1280 / 1440 widths the canvas library, prompt library, assets page, Settings and canvas page show no horizontal scrolling or overlapping controls; the canvas side panel overlays below the top bar on phones with a close button, the bottom toolbar scrolls horizontally without colliding with the zoom control, and fixed-width dialogs fit the viewport. The language switch in Settings applies immediately and persists.
