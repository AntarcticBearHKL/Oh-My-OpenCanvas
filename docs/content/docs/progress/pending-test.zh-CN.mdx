# 待测试

当前版本需要人工验证以下内容：

## 画布节点与编辑

- 节点名称始终显示在卡片上方，没有单节点名称开关；悬停工具栏的「显示标签」开关控制所有节点类型悬停工具栏按钮的文字标签，并在刷新后保留状态。
- 节点卡片默认没有描边，只有选中、关联节点和拖放目标状态会显示轮廓。
- 节点列表与悬停工具栏可以锁定或隐藏节点：锁定后节点不能拖动、缩放、编辑、删除，也不会被框选拿走，但仍可选中以便解锁；隐藏后节点不渲染、不能被点击或作为连线目标，可从节点列表恢复；每次锁定、隐藏或重命名都能用一次撤销还原。
- 底部工具栏的「节点列表」（以及悬停工具栏的「层级」弹层）可打开节点面板，按类型筛选、对多选行批量重命名（单选保留原名，多选追加编号），并逐行切换锁定/隐藏。
- 拖动节点会吸附到 16px 画布网格，但当某条边或中心与另一节点相距 6 个屏幕像素以内时优先使用对齐参考线；任意缩放下松开后的落点都与拖动预览一致。
- 选中两个及以上节点时，选择工具栏显示六个对齐操作（左、水平居中、右、上、垂直居中、下）；选中三个及以上时还会显示水平与垂直等距分布。每个操作只移动选中节点，一次撤销即可还原整次移动。
- 每条连线在中点显示简短的关系标签（参考图 / 参考视频 / 参考音频 / 提示词 / 合成图，派生操作如抠图结果 / 裁剪结果 / 切图结果 / 放大结果 / AI 提升结果 / 局部编辑结果 / 视频截帧 / 生成结果，「组内容」，或无法识别来源时统一的「关联」）；点击标签会选中连线，缩放时标签在屏幕上的大小保持不变。
- 拖动节点时连线跟随同一份位移预览，松开后仍保持连接；拖动过程中只重渲染被拖动的节点，而不是整张画布。
- 图片节点在画布上以最长边 512px 的 WebP 缩略图渲染，只有查看大图时才加载原图；旧图片会在首次渲染时懒生成缩略图。
- 在画布空白处、节点或连线上右键会显示浏览器原生右键菜单；按住 Ctrl 右键拖拽可绘制笔迹，被笔迹穿过的连线会被切断，一次撤销即可恢复。

## 画布导航、布局与画布库

- 左侧面板只显示画布切换器：分组名称表头加「新建」「载入」、当前分组的画布列表（含节点数）、当前画布高亮、拖拽重排和逐行删除；没有搜索框，也没有「素材」或「提示词库」页签。
- 画布按存储顺序排列（不按更新时间排序），新建画布排在最前；拖拽行会显示插入线并调整顺序，不会误触发跳转，顺序在刷新后保留。
- 底部工具栏最左侧的「导出画布」会把画布的节点、连线、视图以及全部图片/视频/音频资源打包成一个 zip 下载，包内 `projects.json` 清单记录格式版本、库名和每个资源对应的文件。
- 切换器和画布库的「载入」都接受导出的 zip，新建画布而不覆盖已有画布，恢复节点、连线与视图并把资源写回本地存储；同名库会复用而不会新建。
- 访问 `/` 会跳转到 `/canvas` 的画布库，`/canvas/:id` 是编辑器；画布库每行显示一个画布及其节点/连线统计、更新时间与移动/导出/重命名/删除操作，行支持拖拽重排并与画布切换器共用同一存储顺序。提示词库是 `/prompts`，资源页是 `/assets`，生成设置在画布节点面板内。
- 底部工具栏在画布区域内居中，窄屏下横向滚动。从左到右依次是：导出画布；选择/平移切换；撤销；重做；输入/输出菜单（资源、录音）；提示词菜单（提示词、音乐提示词、语音提示词、视频提示词）；生成器菜单（图片生成、音乐生成、语音生成、视频生成）；修饰菜单（图片修饰）；智能画布；按需出现的扩展菜单；缩放弹层；节点列表按钮；以及有节点选中时才出现的删除。「视频」媒体节点不再出现在这里。
- 「缩放」工具的弹层提供 5%-500% 滑杆与实时百分比、「重置视图」、小地图开关（开启时高亮）和「快捷键」入口；点击外部或按 Esc 关闭，拖动滑杆时保持打开。
- 坐标标尺渲染在顶栏下方并组成 L 形（上边和左边），随平移、缩放实时更新，缩小到一定程度自动拉大刻度间距，且只作展示、不拦截点击或拖动；每张画布在切换和刷新后都会记住自己的缩放与镜头位置。

## 画布节点面板

- 提示词节点是一个可编辑面板，显示标题、「从预设库选择」入口和提示词输入框；它通过普通连线接入生成节点，生成按钮始终可点击。
- 参考图挂在提示词节点上；每条「参考图 N」连线都有标签，提示词节点为每个参考图显示可拖动的名字芯片，拖进编辑器即在当前光标处插入对应提及。
- 文本节点的悬停工具栏可打开文字样式弹层，设置字体、字号、行高、加粗、斜体、左/中/右对齐与文字颜色；样式随节点保存，颜色未设置时跟随画布主题。
- 「图片生成」节点是单一面板，模型、尺寸、张数与「生成」按钮都内联在节点内，设计尺寸为 412x576 并等比缩放，且始终位于节点最底层；语音生成为 412x312、音乐生成为 412x244、图片修饰节点为 460x644，均按比例缩放。
- 「图片生成」节点的「生成」按钮使用画布淡可可主色（浅色 `#e0cbb0` / 深色 `#c9ac8b`），不是灰色填充。
- 有内容的图片节点始终在左上角按「名称 · 尺寸 · 大小」显示信息，缺失部分自动省略，没有开关；悬停工具栏把上移/下移合并进「层级」弹层。
- 从节点面板打开的弹层（预设库、模型/尺寸选择、文字样式）可以正常交互，画布不会把弹层内的点击当成点击空白，也不会拖动节点。
- 「图片生成」节点的「生成」按钮与其他内联控件在任意尺寸下都保持留白，节点内容按固定设计稿等比缩放而不会被裁切。
- 「视频提示词」是独立面板，提示词输入框下方由它独占视频模式开关（首尾帧 / 参考图）与画面槽位：把图片节点拖到槽位上会高亮该槽位，松手绑定图片节点 id（首帧 / 尾帧，或按顺序填充的最多 4 个参考图槽位），已填充的槽位显示缩略图并可一键清除，清除或绑定的图片丢失后槽位恢复为空，被拖动的图片回弹到原位。「视频生成」节点是固定 412x576 的内联面板，模型、清晰度、比例与时长都在节点内展示（没有模式页签、没有 W/H 输入框、也没有设置弹层），并连接到「视频提示词」节点；两者都从底部工具栏的提示词/生成器菜单创建。「视频」媒体节点不再出现在工具栏，只能从资源节点拖入文件或由生成产生。

## 生成

- 同时发起多次生成时，所有请求统一经一个并发上限为 2 的共享队列执行，排队中的图片仍显示为等待中，而不是一次性全部打到接口。
- 生成失败会自动重试最多 3 次、每次间隔 2 秒，之后才报告失败。
- 生成的图片、视频、音频和文本结果直接排布在画布上，不会自动连回生成节点；只保留用户手动创建的连线。
- 生成中的图片变为成功时会播放一次轻微的放大 + 上浮 + 淡入入场动画（约 0.42s）；已在画布上的图片不会重复播放，系统开启「减少动态效果」时会关闭。
- 生成完成后，图片节点信息条显示从 OpenRouter 响应读取的真实费用（`usage.cost`）并标注来自真实返回；响应没有费用时显示本地估算值并标注为估算。
- 视频生成节点（或视频模式的生成配置节点）选择 `minimax/hailuo-3-max` 时使用 OpenRouter 原生异步视频接口：请求体只携带 model、prompt、duration、resolution、aspect_ratio，以及首尾帧模式的 `frame_images` 或参考模式的 `input_references`（模式与槽位图片读取自连接的「视频提示词」节点，按首帧/尾帧或参考图顺序发送，两者不会同时发送）；视频生成节点内联展示模型、480p/768p、5-15 秒与六种宽高比（1:1 / 3:4 / 4:3 / 16:9 / 9:16 / 21:9），没有 W/H 输入框与设置弹层，不发送 `size` / `generate_audio` / `watermark` / `seed`；其他视频模型（渠道模型与插件脚本）的面板与请求路径保持不变。

## 智能画布

- 「智能画布」是固定比例、可选 1K/2K/4K 合成分辨率的画板（默认 16:9 / 2K），支持背景颜色（透明 / 白 / 黑 / 自定义）与背景不透明度；切换比例会按比例缩放画板。拖到画板上的图片成为板内图层并仍是普通可编辑节点，显示「已置入画板」角标和虚线描边，渲染在画板之上。
- 画板的「一键排版」是下拉菜单，提供网格、单行、单列、主图四种模板；每种模板都按比例缩放不拉伸、居中排列，并可撤销。
- 画板面板的「图层」弹层按前后顺序列出板内图片，含缩略图、标题、显示/隐藏开关和上移一层/下移一层；隐藏的图层从画板和合成图中消失，重排会同时改变屏幕叠放与合成绘制顺序。每个图层可选 16 种 Photoshop 等效混合模式并单独调整不透明度，预览用 CSS `mix-blend-mode`、导出用对应的 canvas `globalCompositeOperation`。
- 把画板拖到另一个画板上会成为板内图层；父画板按图层顺序递归渲染嵌套画板并按各自矩形裁剪，画板不能拖入自身或子孙。拖动画板会带动整棵板内子树，数据里若已有循环，渲染与合成都直接跳过而不是死循环。
- 画板不实时渲染合成结果：双击打开大图预览，悬停工具栏的「存为图片节点」会按需合成（递归嵌套画板）并在右侧生成图片节点。
- 画板面板的「添加文字」在画板中心添加可编辑标注，可拖动、双击编辑（Esc 或失焦提交，清空即删除），悬停时显示删除按钮；标注渲染在板内图片之上，并在合成图中按相同位置、字号和颜色出现。

## 图片工具

- 图片节点悬停工具栏显示已启用的快捷工具，默认包含信息、删除、存入资产、下载、局部编辑、裁剪、抠图、切图、分辨率、图片分析、识别文字、分割和复制；「显示标签」开关会为所有节点类型显示按钮文字标签并持久化。
- 「抠图」在 Web Worker 中运行约 42MB 的背景移除模型，并在右侧新增一个透明底 PNG 节点、建立连线并选中；模型可在 设置 → 本地模型 下载，也可首次使用时自动下载并显示进度，全程界面保持可操作。
- 「切图」打开点选分割弹窗（左键点前景、Alt 或右键点背景，支持撤销上一点与清空），在本地运行 MobileSAM（ONNX，首次按需下载约 45MB 并缓存），显示所选蒙版的 IoU 与叠加预览，并在右侧生成透明底结果节点；编码器每张图只运行一次，后续加点仍保持流畅。
- 「分辨率」提供三个页签：算法放大（1K/2K/4K 预设、算法选择与输出预览，源图最长边达到目标时禁用确认）、算法缩小（1024/768/512 预设加 64-4096px 自定义目标，仅当目标小于源图最长边时可确认）和 AI 提升（2x/4x 倍数与可编辑提示词，以该图片为唯一参考图调用已配置的图片模型）。本地结果连线显示放大结果、AI 结果显示 AI 提升结果，两种情况都会选中新节点。
- 「图片分析」弹窗显示图片主色板、EXIF 键值列表（没有时给出空状态提示）和感知哈希；选择比例（1:1 / 4:3 / 3:4 / 16:9 / 9:16）并确认后，会在右侧用智能裁剪生成新的图片节点。
- 「识别文字」把图片发给已配置的文本模型，并在右侧创建并选中一个文本节点；未配置文本模型或 Key 时会打开设置，未识别到文字会提示错误且不建节点，请求失败会显示错误原因而不会卡在加载提示。
- 双击图片打开大图预览，底部提供下载按钮；悬停工具栏同样提供下载与存入资产。
- 局部编辑要求已涂抹区域并填写修改要求；确认后会在原图下方生成「遮罩标注」图片节点（原图叠加半透明蓝色涂抹区域），并在右侧生成同时接收两者连线的结果节点；请求按两张普通参考图发送、提示词按索引说明，不携带 `mask` API 参数。画笔圆环跟随鼠标，缩放时涂抹保持流畅。

## 资源节点与本地文件夹

- 工具栏与创建菜单提供一个「资源」节点，每个节点只绑定一个本地文件夹：文件夹里的文件以纯文件名的纵向列表展示（不显示缩略图或网格，上限 200 个文件并给出状态提示），把文件拖到画布上即创建对应节点，点击则在画布中心插入，重新打开画布或切换画布都会恢复该节点的绑定与文件列表。
- 每个「资源」节点各自绑定并记住自己的文件夹（按节点单独保存在 IndexedDB，不写进节点 metadata 或画布项目数据）；新建的资源节点默认不绑定、列表为空，不会继承其他节点或上次会话的文件夹。
- 把图片节点拖到「资源」节点上松手会动画回弹到原位，把图片写入该节点绑定的文件夹，显示「保存中 → 成功/失败」并刷新文件列表；拖动时该节点会高亮为拖放目标。节点不再有独立的输出文件夹，也不会自动写入上游结果。
- 「资源」节点顶部新增来源切换（本地文件夹 / 插件缓存），选择会写入节点 metadata，重新打开画布或切换画布后保留；两种来源各自保留自己的表头操作与列表。
- 安装并连接 OpenCanvas 浏览器插件后，切到「插件缓存」会列出插件缓存里的图片文件名（与文件夹列表一样最多 200 条并显示数量），每行可拖到画布或点击插入为普通图片节点；未安装插件时显示「未检测到插件」与安装提示且不报错，本地文件夹行为保持不变。

## 设置

- 页签：设置弹窗按顺序只显示这些页签：接口、外观、生成、本地模型、提示词来源、本地存储、成本、Agent、关于。
- 「接口」页只填 OpenRouter API Key，Base URL 固定为 `https://openrouter.ai/api/v1`；图片模型写死为 `openai/gpt-image-2.5-sunburst`，未配置 Key 时禁止生成。
- 「外观」包含界面语言、白/黑主题（默认白）以及新建画布使用的画布背景（点 / 线 / 空白，默认点）；已打开的画布会立即跟随这些设置。
- 「本地模型」列出每个本地模型（抠图、分割）的大小与状态，并提供下载 / 重新下载 / 删除；删除会先确认，然后清除下载状态与浏览器缓存的模型文件，状态回到未下载。
- 「本地存储」只读取 `infinite-canvas` 数据库，显示 IndexedDB 占用、站点总占用、浏览器配额与使用率，以及各对象仓库的记录数与内容体积，刷新时页面保持可用；其中本地模型占用行点击可跳转到本地模型页签。
- 「成本」按 USD 显示总花费（只计已定价记录）、记录总数与未定价条数，按模型拆分生成次数与花费（无定价显示「未定价」），并列出最近记录的时间、模型、数量与成本；未定价记录不会显示为 $0.00，清空会清掉列表。
- 「关于」显示扁平快捷键列表（按键在深浅色主题下都清晰）和版本区块，点击版本号打开版本更新弹窗。
- 设置弹窗是纯色面板，左侧为纵向页签，内容区固定高度并内部滚动；切换页签不会移动或改变外框尺寸，没有说明文字、没有导入/导出、也没有底部「完成」按钮。
- 设置按钮旁的账户用量入口可打开面板，查看当前 API Key 的总用量、今日/每周/每月用量与剩余额度（未设上限时明确提示）；打开面板时与每次生成完成后自动刷新，也可手动刷新。界面与页面标题显示的产品名为 OpenCanvas。

## 画布 MCP 与 Agent 权限

- 画布浏览器桥接与 HTTP MCP 端点融合进前端应用，与画布共用同一端口。执行 `cd web; npm run dev` 后，`http://127.0.0.1:3000/health` 与 `/config` 正常返回，`GET /` 与 `/canvas/<id>` 仍返回前端页面，MCP 客户端连接 `http://127.0.0.1:3000/mcp` 应能看到 33 个画布工具。画布在同源下自动连接，无需 token 或配置文件。
- `canvas_create_node`、`canvas_apply_ops` 的 `add_node` 与 `delete_node` 支持全部内置节点类型（文本、提示词、音乐提示词、语音提示词、视频提示词、图片、视频、音频、生成配置、图片生成、语音生成、音乐生成、视频生成、智能画布、资源、录音、图片修饰）；未知类型会被拒绝，且不存在 `canvas_group_nodes` / `canvas_ungroup_nodes`。
- 节点工具：MCP 客户端可设置锁定/隐藏（`canvas_set_node_flags`）、批量重命名（`canvas_bulk_rename`，单节点用原名，多节点编号为「标题 1」「标题 2」…）、对齐/等距分布（`canvas_align_nodes`，分布需 3 个以上节点）和复制节点（`canvas_duplicate_node`，默认偏移 40/40 并选中副本）。未知 id 会被忽略而不会破坏画布。
- 设置 → Agent 页为每类画布操作提供一个开关（共 10 类，默认全部允许）；关闭某类后该操作会被拦截、弹出提示并计入被拦截数。
- 每次 Agent 操作批次都会记入 Agent 审计日志，包含时间、操作数、被拦截数与操作摘要；日志最多保留最近 100 条，「清空」清空列表，「恢复默认」重新开启全部权限。回放一条记录会重新执行同样的操作，并新增一条标记为「已回放」的记录。

## 外观与响应式布局

- 应用与画布外壳（导航、画布顶栏、底部工具栏、悬停/选择浮层、侧栏、小地图）使用带细边框的半透明毛玻璃表面；画布节点、弹层、工具栏和资产卡片不使用投影，状态只用边框和轮廓环表达。
- 应用与画布共用一套暖色 token，画布库、设置、下拉与输入控件在深浅色下都与画布同一套配色，切换主题会整体更新。
- 所有界面文字使用圆体字体栈（英文 Baloo 2、简体中文资源圆体），支持真实的 400/700 字重；字体 CDN 不可用时回退到系统圆体。
- 节点设置、画板、图层与文字样式弹层共用同一进入动画，系统开启「减少动态效果」时会自动关闭。
- 在 375 / 768 / 1280 / 1440 宽度下，画布库、提示词库、资源页、设置页和画布页都不出现横向滚动或控件重叠；手机端画布侧栏覆盖在顶栏下方并带收起按钮，底部工具栏横向滚动且不与缩放控件重叠，固定宽度弹窗不超出屏幕。设置中的语言切换立即生效并在刷新后保留。
